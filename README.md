💇 Parlour Management System

A web-based Parlour Management System developed using Core PHP and MySQL.
This project is designed to help manage parlour services, customers, appointments, staff and administrative activities through an easy-to-use web interface.

📌 Project Overview

The Parlour Management System provides separate functionality for users and administrators.

Customers can explore available parlour services and book appointments, while administrators can manage services, customers, appointments and other parlour-related activities from the admin panel.

🎯 Purpose of the Project

The main purpose of this project is to provide a digital solution for managing daily parlour operations such as:

Customer management
Service management
Appointment scheduling
Staff management
Invoice management
Sales reporting

The project also demonstrates practical implementation of CRUD operations, database connectivity, authentication and web application development using PHP and MySQL.

🔐 Source Code

The complete source code of this project is maintained privately.
